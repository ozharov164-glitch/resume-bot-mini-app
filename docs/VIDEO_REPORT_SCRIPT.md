# ResumeBot — Сценарий видеоотчёта (озвучка)

> Откройте `VIDEO_REPORT_RESUME_BOT.html` в браузере на весь экран и листайте слайды по таймингу ниже (~6–8 минут).

---

## Слайд 1 — Вступление (0:00–0:45)

ResumeBot — это Telegram Mini App, которое за пять минут помогает человеку без IT-опыта собрать профессиональное резюме. Целевая аудитория — продавцы, водители, кладовщики, менеджеры: те, кому нужно первое или новое резюме под hh.ru. Бот в Telegram — @resumeez_bot.

---

## Слайд 2 — Архитектура (0:45–1:45)

Продакшен разделён на три части. Фронтенд Mini App хостится на GitHub Pages — это бесплатный HTTPS и не нагружает VPS. Весь «тяжёлый» backend — на VPS: FastAPI, искусственный интеллект, PDF, платежи и webhook. Пользователь открывает Mini App из бота, фронт обращается к API по защищённому HTTPS. Генерация текста идёт через OpenRouter и модель DeepSeek V4 Flash.

---

## Слайд 3 — Что реализовано (1:45–2:45)

Собран полный MVP. Frontend: пошаговый диалог, превью резюме, оплата, экран успеха — с темой Telegram и тактильной отдачей. Backend: авторизация через initData, генерация резюме, платежи Stars и ЮKassa, отправка PDF. Бот запускает Mini App и доставляет файл в чат. PDF собирается WeasyPrint из HTML-шаблона. База — Supabase. Фронт автоматически деплоится через GitHub Actions.

---

## Слайд 4 — Путь пользователя (2:45–3:45)

Пользователь нажимает «Создать резюме», отвечает на вопросы, backend проверяет подпись Telegram и выдаёт токен. ИИ возвращает структурированное резюме — пользователь видит превью. После оплаты Stars или ЮKassa PDF уходит в личный чат. Секреты не хранятся в репозитории — только на сервере в файле .env.

---

## Слайд 5 — ИИ (3:45–4:45)

Используем DeepSeek V4 Flash — недорого и хорошо по-русски. Запросы маршрутизируются только на самые быстрые провайдеры OpenRouter. Промпт настроен на баланс: без лишних токенов, но с полноценным HR-качеством — живой язык, конкретика, без выдуманного опыта. Fallback на другую модель — только если первая попытка упала.

---

## Слайд 6 — Деплой (4:45–5:30)

На VPS проект лежит в /opt/resumebot, сервисы systemd, HTTPS через Caddy. API отвечает на healthcheck. Mini App на GitHub Pages. Оба контура работают.

---

## Слайд 7 — Структура кода (5:30–6:00)

Репозиторий monorepo: frontend, backend, bot, deploy-конфиги и скрипты автоматизации VPS.

---
