Глава 2

Что реализовано

Frontend (React + Vite) 8-шаговый онбординг, превью резюме, экран оплаты, успех. Тема Telegram, haptic, Zustand.
Backend (FastAPI) Auth по initData, генерация резюме, платежи, скачивание PDF, healthcheck.
Telegram-бот /start с кнопкой Web App, доставка PDF после оплаты.
База данных Supabase (PostgreSQL): users, resumes, payments.
PDF WeasyPrint + Jinja2 шаблон resume_classic.html.
CI/CD GitHub Actions → автодеплой фронта на Pages при push в main.
Глава 3

Путь пользователя

  1. Открывает бота @resumeez_bot → «Создать резюме»
  2. Mini App: имя, должность, опыт, образование, навыки, город, о себе
  3. Backend проверяет подпись Telegram → выдаёт JWT
  4. ИИ формирует JSON-резюме → превью на экране
  5. Оплата: Telegram Stars (основной) или ЮKassa (fallback)
  6. PDF генерируется и приходит в личный чат с ботом

Безопасность

  • Секреты только на VPS в /opt/resumebot/backend/.env
  • В GitHub — только код, без ключей
  • Каждый API-запрос защищён JWT после верификации initData
Глава 4

ИИ-слой (OpenRouter)

ПараметрЗначение
Основная модельdeepseek/deepseek-v4-flash
Fallbackdeepseek/deepseek-v3.2 (только при ошибке)
Провайдеры (только быстрые)parasail, alibaba, deepseek, morph
Маршрутизацияsort: latency, provider.only
Лимит ответа1600 токенов (достаточно для качественного резюме)
ФорматJSON (response_format: json_object)

Баланс: качество ↔ экономия

  • ✓ Полные HR-правила в system prompt (hh.ru, живой язык, без выдуманного опыта)
  • ✓ Структурированный ввод от пользователя — без «воды» в запросе
  • ✓ Нет двойных вызовов модели «на всякий случай»
  • ✓ Логирование prompt/completion tokens в логах API
  • Ориентир стоимости: ~0,03–0,05 ₽ за одно резюме
